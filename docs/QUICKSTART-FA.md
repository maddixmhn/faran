# راهنمای فارسی اجرای محلی

این راهنما یک محیط آزمایشی تازه برای دانشگاه فاران و ارزیاب دکتر سلیمانی می‌سازد. نسخه‌های عمومی گزارش و شواهد در ورسل در دسترس‌اند. برای اجرای سرویس‌ها، Docker را روی دستگاه خودت راه‌اندازی کن.

## اجرای کامل با یک فرمان

پیش‌نیازها Docker Desktop یا Docker Engine با افزونهٔ Compose، Git و Python 3.10 یا جدیدتر هستند. Docker باید روی حالت کانتینر لینوکس باشد. نصب نخست برای دریافت ایمیج‌ها، کد Moodle و مخزن ارزیاب اینترنت می‌خواهد.

```bash
git clone https://github.com/maddixmhn/faran.git
cd faran
python scripts/start.py
```

اگر فرمان Python روی سیستم با نام `python3` نصب است، همان نام را استفاده کن. اسکریپت تا آماده‌شدن سرویس‌ها منتظر می‌ماند و آدرس‌ها را چاپ می‌کند. دریافت اولیه و نصب Moodle ممکن است روی دستگاه کند بیش از چند دقیقه طول بکشد. در آزمون Windows، نصب تازه پس از ایجاد صدها جدول هنوز در حال نصب افزونه‌های همراه Moodle بود. ایمیج رسمی Paperclip برای Linux amd64 حدود ۴٫۶ گیگابایت دانلود فشرده دارد. زمان دریافت ایمیج‌ها به سرعت اینترنت بستگی دارد.

| سرویس | نشانی پیش‌فرض |
| --- | --- |
| دانشگاه دیجیتال فاران و دانلود گزارش | http://localhost:18000 |
| سایت ارزیاب و دانلود مقاله | http://localhost:18001 |
| n8n و تاریخچهٔ گردش‌کار | http://localhost:15678 |
| کنسول Paperclip | http://localhost:13100 |
| Moodle | http://localhost:18700 |

## ورود و اجرای اولین نمونه

1. صفحهٔ عمومی فاران یا ارزیاب را باز کن. لینک دانلود مقاله بالای صفحه قرار دارد. ورود نمایشی به داشبورد با `admin` / `admin` است.
2. در n8n، مالک نمونه را در نخستین ورود ایجاد کن. برای آزمایش ارتباط داخلی، از منوی ورود فایل، `infra/workflow/workflows/faran-paperclip-health.json` را وارد کن و **Execute workflow** را بزن. گرهٔ HTTP وضعیت Paperclip را از شبکهٔ Compose می‌خواند. این آزمایش دستی است و دادهٔ آموزشی را تغییر نمی‌دهد.
3. در Moodle، نام کاربری `admin` است. مقدار `MOODLE_ADMIN_PASSWORD` را از `.faran/faran-demo.env` روی دستگاه خودت بخوان. نصب نخست Moodle را با شرایط مجوز نرم‌افزار آن راه‌اندازی می‌کند. دادهٔ آزمایشی خودت را در این نمونه بساز.
4. Paperclip در حالت احراز هویت اجرا می‌شود. برای ثبت مالک اول، مسیر راه‌اندازی گزارش‌شده توسط خود سرویس را دنبال کن. خروجی محلی را با `docker compose --env-file .faran/faran-demo.env logs paperclip` ببین و لینک ورود را خصوصی نگه دار.
5. برای بررسی ارزیاب، در داشبورد «تحلیل مأموریت‌های نیمسال» را بزن یا فایل `semester/events.json` از مخزن ارزیاب را بارگذاری کن. این فایل دادهٔ آموزشی ساختگی برای نمایش قابلیت‌های تحلیل است.

## وضعیت، توقف و خطای نصب

```bash
python scripts/start.py status
python scripts/start.py stop
python scripts/start.py
```

توقف، داده‌ها را در volumeها نگه می‌دارد. پوشهٔ `.faran` تنظیمات و رمزهای تولیدشدهٔ همین نصب را نگه می‌دارد. برای ادامهٔ کار همین فایل را حفظ کن. در صورت تداخل پورت، پیش از اجرا مقدار `FARAN_WEB_PORT`، `FARAN_EVAL_PORT`، `FARAN_N8N_PORT`، `FARAN_PAPERCLIP_PORT` یا `FARAN_MOODLE_PORT` را در محیط شل تغییر بده. برای Moodle، نشانی انتخاب‌شده در نصب نخست در تنظیمات سامانه ذخیره می‌شود.

برای بررسی سرویس ناموفق، مثلاً Moodle، از دستور زیر استفاده کن:

```bash
docker compose --env-file .faran/faran-demo.env logs --tail 70 moodle
```

اگر دریافت ایمیج شکست خورد، دسترسی Docker به GitHub، Docker Hub و مخزن n8n را بررسی کن. برای محیط دارای mirror معتبر، `FARAN_MOODLE_PHP_IMAGE` نام ایمیج پایهٔ PHP را تعیین می‌کند. فایل `compose.yaml` همهٔ ایمیج‌ها و پورت‌ها را نشان می‌دهد. هیچ فایل دادهٔ Docker یا رمز این پروژه برای راه‌اندازی لازم نیست.

## اجزای بسته و ریشهٔ آن‌ها

| جزء | دلیل استفاده |
| --- | --- |
| دو سایت Nginx | پوستهٔ وب و گزارش‌ها همان فایل‌های مخزن هستند. نسخهٔ ارزیاب در Compose به commit مشخص GitHub متصل است. |
| n8n و worker | ایمیج رسمی به digest قفل شده است. Postgres و Redis اجزای آماده برای ذخیره و صف‌اند. |
| Paperclip | ایمیج رسمی نسخهٔ ثبت‌شده برای مدیریت نقش و گردش کار آزمایشی است. |
| Moodle | کد ۴٫۵٫۱۶ از commit رسمی و تصویر PHP/Apache تیم Moodle ساخته می‌شود. پایگاه داده و پیکربندی در volumeهای جدا حفظ می‌شوند. |

این بسته برای نصب تازه است. نتیجه‌های تاریخی سمینار و تصاویر در صفحات گزارش قابل مطالعه‌اند. فایل‌های خصوصی Moodle، حساب نهاد آموزشی و تاریخچهٔ محیط نویسنده جزو بستهٔ نصب نیستند.
